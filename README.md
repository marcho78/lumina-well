# LUMINA — The Well of Lights

Portrait cascade puzzle. Drop lights. Match three. Ascend 480 wells.

**Play:** open `index.html` (or the GitHub Pages URL on this repo).

This snapshot includes:

- Playable static game (`index.html`, `app.css`, `app.js`)
- Current Grok Build source (`src/game`, `src/components/lumina`, `src/styles.css`) — gold ceremonial UI, workshop, how-to-play, well home

Save data lives in `localStorage` (`lumina.well.v1`).
